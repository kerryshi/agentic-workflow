# Grill questions

Answer inline under each question, then resume the run.

1. For a multi-size item (wonton soup, hot & sour soup, chicken fried rice, chicken lo mein, white rice) asked about without a size, should the reply state both prices (e.g. 'pint $3.50, quart $5.95'), or ask which size before quoting a price?
   A: State both prices in one reply (e.g. 'Wonton soup is $3.50 for a pint, $5.95 for a quart'). On a phone call, quoting both is faster than a clarifying turn, and it never invents a single price for a multi-size item.

2. Should one utterance be able to price multiple items at once (e.g. 'how much are the egg rolls and crab rangoon'), or is single-item-per-question sufficient for this slice?
   A: Single-item-per-question is sufficient for this slice. If an utterance names multiple items, answering the first recognized item or using the existing fallback is acceptable; multi-item pricing is explicitly out of scope (keep the diff small).
